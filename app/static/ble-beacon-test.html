ทดสอบรับ Beacon พร้อมกัน

ใช้ firmware smartcheck_beacon.ino ชื่อ SC-TEST1 เปิดหน้านี้บน HTTPS ใน laptop, Android และ Bluefy พร้อมกัน หน้านี้ไม่เชื่อมต่อ GATT และไม่บันทึกการเข้าเรียน

กดสแกน 30 วินาที หรือเลือกอุปกรณ์เพื่อทดสอบ watchAdvertisements หากมี API รองรับ

Diagnostic version: manufacturer-B

ยังไม่ได้ทดสอบ


ผ่านเมื่อหลายเครื่องได้รับ TEST-101 ต่อเนื่องในช่วงเวลาเดียวกัน แล้วปิดบอร์ดและจำนวนแพ็กเก็ตหยุดเพิ่ม การเห็นชื่ออุปกรณ์หรือมี API อย่างเดียวไม่ถือว่าผ่าน


Chrome อาจต้องเปิด Experimental Web Platform features ใน chrome://flags แล้วเปิด browser ใหม่ หาก Bluefy แสดงเฉพาะ API เฉพาะของแอป ให้ส่งผลความสามารถพร้อม API Reference ของ Bluefy เพื่อยืนยันวิธีเรียกก่อนใช้
