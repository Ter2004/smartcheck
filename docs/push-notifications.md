# แจ้งเตือนเปิดคาบ (อาจารย์กดเปิดคาบ + แจ้งเตือนในแอป Android)

## ภาพรวม
1. **อาจารย์กด "เปิดคาบ"** ในหน้าหลักของอาจารย์ (คาบวันนี้) แล้วใส่จำนวนนาทีที่นับว่า "ทันเวลา" (ค่าเริ่ม 5)
   - กดได้ตั้งแต่ 15 นาทีก่อนเวลาเริ่ม
   - ถ้าเลยเวลาเริ่ม 15 นาทีแล้วอาจารย์ยังไม่กด ระบบเปิดเองโดยใช้ 5 นาที
   - คาบปิดเองตอนหมดเวลาตามตาราง
2. **เช็คชื่อภายในช่วงทันเวลา = มาเรียน**, เลยช่วงนั้น = สาย (ยังเช็คได้จนคาบปิด)
3. **แจ้งเตือนในแถบด้านบนของมือถือ** (แอปปิดอยู่ก็เด้ง) ส่งเฉพาะนักศึกษาในวิชาที่ยังไม่เช็คชื่อ
   - ตอนเปิดคาบ: "SE101 เปิดเช็คชื่อแล้ว — แตะเพื่อเช็คชื่อ มาเรียนทันเวลาถึง 08:05 น."
   - ตอนเหลือ 1 นาทีก่อนนับสาย: "SE101 ยังไม่ได้เช็คชื่อ — อีก 1 นาทีจะนับสาย มาเรียนได้แล้ว" (แทนที่อันแรก ไม่ซ้อน)
   - แตะแล้วเข้าหน้าเช็คชื่อ กล้องเปิดทันที แอปหาบอร์ดไปพร้อมกัน
   - ไม่อยู่ในห้อง: ขึ้น "คาบเปิดแล้ว แต่ยังไม่พบสัญญาณห้องเรียน — มาเข้าห้องเรียนแล้วกด ลองใหม่"
   - เช็คชื่อแล้ว แจ้งเตือนหายเอง

โค้ด: `app/services/class_open.py` (กติกาเปิด/สาย), `app/services/class_push.py` + `fcm.py` (ส่ง),
`app/routes/push.py` (รับ token จากแอป), `app/static/js/push_notifications.js` (ในแอป)

## ขั้นตอนเปิดใช้ (ทำครั้งเดียว)

### 1. รัน migration (ต้องทำก่อน restart เซิร์ฟเวอร์)
Supabase → SQL Editor → วางทั้งไฟล์ `database/migrations/20261103_teacher_open_and_push.sql` → Run
แล้วรันส่วน Verification ท้ายไฟล์ (เอาเครื่องหมาย `--` ออก) แถวสุดท้ายต้องเป็น `END`

> ถ้ายังไม่รัน migration แต่ต้อง restart เซิร์ฟเวอร์: ใส่ `SESSION_OPEN_MODE=schedule` ใน `.env` ระบบจะทำงานแบบเดิม (เปิดคาบเองตามตาราง)

### 2. สร้างโปรเจกต์ Firebase (ฟรี)
1. เข้า https://console.firebase.google.com ด้วยบัญชี Google → **Create a project** → ตั้งชื่อ เช่น `smartcheck` → Google Analytics ปิดได้
2. ในโปรเจกต์ กดไอคอน **Android** (Add app)
   - **Android package name:** `com.smartcheck.app` (ต้องตรงตัวอักษร)
   - ชื่อเล่นใส่อะไรก็ได้ ช่อง SHA-1 เว้นว่าง
   - **Register app** → **Download google-services.json**
   - ขั้นที่เหลือ (เพิ่ม SDK) กด Next/ข้ามได้ ผมใส่ไว้ในโค้ดแล้ว
3. วางไฟล์ไว้ที่ `android-app/google-services.json` (ไฟล์นี้ไม่ขึ้น git)
4. **Project settings** (เฟือง) → แท็บ **Service accounts** → **Generate new private key** → ได้ไฟล์ JSON
   - **ไฟล์นี้เป็นความลับ** (ส่งแจ้งเตือนในนามโปรเจกต์ได้) ห้ามส่งให้ใคร ห้ามขึ้น git
   - วางไว้ที่ `instance/firebase-service-account.json` (โฟลเดอร์ `instance/` ไม่ขึ้น git)
5. แท็บ **Cloud Messaging** ใน Project settings: ตรวจว่า **Firebase Cloud Messaging API (V1)** เป็น Enabled
   (โปรเจกต์ใหม่เปิดไว้แล้ว ถ้าไม่ใช่ ให้กดเปิด)

ชื่อปุ่มในหน้า Firebase อาจต่างเล็กน้อยตามเวอร์ชันของหน้าเว็บ

### 3. ตั้งค่าเซิร์ฟเวอร์
เพิ่มใน `.env`:
```
FCM_SERVICE_ACCOUNT_FILE=instance/firebase-service-account.json
```
แล้ว restart เซิร์ฟเวอร์ (log ไม่ควรมี `[FCM] cannot read FCM_SERVICE_ACCOUNT_FILE`)

ค่าอื่นที่ปรับได้ (มีค่าเริ่มแล้ว ไม่ต้องใส่):
| ค่า | เริ่มต้น | ความหมาย |
|---|---|---|
| `SESSION_OPEN_MODE` | `teacher` | `schedule` = แบบเดิม เปิดเองตลอดช่วงคาบ |
| `CLASS_ON_TIME_MINUTES` | 5 | ช่วงทันเวลาเริ่มต้น |
| `CLASS_AUTO_OPEN_AFTER_MINUTES` | 15 | อาจารย์ไม่กด ระบบเปิดเองหลังเวลาเริ่มกี่นาที |
| `CLASS_EARLY_OPEN_MINUTES` | 15 | กดเปิดก่อนเวลาเริ่มได้กี่นาที |
| `TEACHER_SESSION_DAYS` | 120 | อาจารย์ log in ค้างได้กี่วัน |

### 4. Build แอปใหม่แล้วลงทับ
```
cd android-app
node build-apk.js https://ที่อยู่เซิร์ฟเวอร์
```
บรรทัดท้ายต้องขึ้น `notifications: on` → ลงแอปทับ (adb install -r) → **log in ใหม่ 1 ครั้ง**
ครั้งแรกแอปจะถาม **"อนุญาตให้ส่งการแจ้งเตือน"** → อนุญาต

### 5. Xiaomi / Redmi (HyperOS, MIUI)
ถ้าปัดแอปทิ้งแล้วแจ้งเตือนไม่เด้ง [สมมติฐาน ยังไม่ได้ทดสอบ]:
ตั้งค่า → แอป → SmartCheck → **เปิดอัตโนมัติ (Autostart): เปิด** และ **ประหยัดแบตเตอรี่: ไม่จำกัด** และ **การแจ้งเตือน: อนุญาตทั้งหมด**

## ทดสอบ
1. มือถือ: log in std1 ในแอปใหม่ → อนุญาตแจ้งเตือน → **ปัดแอปทิ้ง** (หรือกดปุ่ม Home)
2. อาจารย์ (คอม): หน้าหลัก → คาบวันนี้ → ใส่นาที → **เปิดคาบ**
3. มือถือ: แจ้งเตือนควรเด้งภายในไม่กี่วินาที → จับเวลา [วัด]
4. แตะ → หน้าสแกนหน้า → เช็คชื่อสำเร็จ → แจ้งเตือนหายจากแถบ
5. ไม่เช็คชื่อ: ตอนเหลือ 1 นาทีต้องเด้งอีกครั้ง (แทนอันเดิม)
6. ถอยออกนอกระยะบอร์ดแล้วแตะ: ต้องขึ้น "คาบเปิดแล้ว แต่ยังไม่พบสัญญาณห้องเรียน"

ดู log ฝั่งเซิร์ฟเวอร์: `[PUSH] sent=… invalid=… failed=…`

## ข้อจำกัด
- **iPhone ไม่ได้รับแจ้งเตือน** (ยังไม่มีแอป iPhone) ใช้รหัสบนจออาจารย์ตามเดิม
- คาบที่ admin สร้างเอง (หน้า admin → สร้างคาบ) ไม่มีเวลาจบในตาราง หลังอาจารย์กดเปิด ระบบไม่ปิดให้ (เป็นแบบนี้มาก่อนแล้ว)
- แจ้งเตือน "เหลือ 1 นาที" ตั้งเวลาไว้ในเซิร์ฟเวอร์ ถ้าเซิร์ฟเวอร์รีสตาร์ทระหว่างนั้น จะส่งจากรอบเช็คทุก 1 นาทีแทน (คลาดได้ไม่เกิน ~1 นาที)
